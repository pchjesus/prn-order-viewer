2. 기존 자료·의사결정 보호, 가능한 최소 변경 적용.
3. 수정 범위에 따른 기능 검증 및 영향받는 기존 기능 회귀검증.
4. 관련 문서 갱신 후 목적이 드러나는 커밋 메시지 사용.
5. 원격 푸시 후 경로, 커밋 SHA, 검증 상태 확인.
