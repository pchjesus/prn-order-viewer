# PRN Order Viewer — 상세 기획 v0.1 (구현 전)

## 목표

가상 EMR의 전체 약물 처방에서 PRN 약물만 정확하게 필터링해, 약물명·적응증·조건·상태를 빠르게 탐색하는 읽기 전용 시연용 화면 설계. **실제 nU 복제·연동 아님**.

## 요구사항

- FR-01 가상 환자 선택: 선택된 환자의 처방만 노출
- FR-02 전체 약물: 정규 및 PRN 약물 처방 전체 조회
- FR-03 PRN 약물: `order_type=prn`만 조회
- FR-04 처방 상세: 원래 가상 처방의 핵심 정보 및 원문 확인
- FR-05 약물명·처방 적응증 검색
- FR-06 처방 상태 표시; `active`를 투여 가능 표시로 사용 금지
- FR-07 상태 필터, 검색과 결합 가능
- FR-08 누락값 `미기재/미검증` 명시; 값 생성 금지
- FR-09 개별 처방 ID 고유 유지, 동일 성분 처방 병합 금지

## UI 구조 제안

1. 상단: PRN Order Viewer / DEMO 비공식 시스템 고지
2. 환자 선택: 가상 이름·ID
3. 전체 약물 / PRN 약물 탭
4. 검색 입력 + 상태 필터
5. 메인 처방 목록 표: 상태, 약물명, 1회 용량, 투여 경로, 적응증, 간격
6. 우측 상세 패널: 주문 ID, 시작/종료, 특수 지시, 원문, 누락 항목
7. 모바일: 목록 -> 상세 전환, 중요 처방정보 축소/숨김 금지

## 데이터 분리

- `MedicationCatalog`: 약물 후보 마스터(검증 상태 포함)
- `Patient`: 가상 환자 정보
- `MedicationOrder`: 환자별 구체적인 가상 처방 및 PRN 여부

## 제외 사항

실제 환자 데이터, 병원 nU 연동, 용량 자동 추천, 투약 가능 시간 자동 계산, 처방 등록·수정, 투여 기록 입력, 임상 의사결정 자동화, 사용자 인증/백엔드. 초기 데이터는 투여 지시가 불완전한 **스키마 테스트용**.

## UX 확정 결정 (2026-10-10)

1. **최초 진입 탭은 `전체 약물`**. 선택된 가상 환자의 정규(`regular`) 및 PRN(`prn`) 처방을 함께 조회하고, 한 번의 탭 전환으로 `PRN 약물` 전용 목록으로 이동한다. 이는 실제 nU 초기 화면을 그대로 재현했다는 의미가 아니다.
2. **PRN 목록의 기본 상태 필터는 `전체`**. `active`, `on-hold`, `stopped` 등 존재하는 **모든 처방 상태**를 기본적으로 누락 없이 표시한다. 사용자가 상태 필터를 선택할 때만 해당 상태로 범위를 좁힌다.
3. **PRN 전체 상태 보기에서는 `active` 처방을 상단에 배치**한다. 나머지 상태의 항목도 목록에 남으며, 동일 우선순위 그룹에서는 입력 데이터의 기존 순서를 유지한다(안정 정렬). 개별 처방을 병합하거나 원본 상태값을 변경하지 않는다.
4. **`active`는 처방의 상태이며 투여 가능 판정이 아니다.** 처방의 유효 여부와 환자 상태·재투여 조건 판단을 혼동하는 안내를 제공하지 않는다.
5. 환자 선택/검색/상태 필터/상세 조회 기능은 위 기본값과 독립적으로 기존 요구사항을 따른다. 상태 필터와 정렬은 보이는 목록에만 적용하고 원본 가상 처방 데이터는 수정하지 않는다.

## 테스트 설계(미실행)

- TC01 PRN만 필터링, TC02 전체 복원, TC03 동종 약물 별도 처방 유지
- TC04 중지/보류 상태의 표현, TC05 PRN 0건 안내
- TC06 조건 누락(용량·적응증 등)을 표시, 값 생성 금지
- TC07 검색·상태 필터 조합, TC08 환자 변경 시 정보 혼입 방지
- TC09 목록·상세·원문 일치, TC10 데스크톱/모바일 가독성
- TC11 최초 진입 시 전체 약물 탭 선택 및 정규·PRN 함께 표시
- TC12 PRN 탭 최초 진입 시 상태 필터 `전체`, 모든 상태 노출, `active` 우선 정렬, 나머지 순서·원본 데이터 불변
